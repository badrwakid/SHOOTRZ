1 · Design Direction
CINEMATIC DIAGNOSTIC EARNED
Cinematic — scores and statuses should feel like broadcast overlays, not web form inputs. Glows, gradients, and emitted light. Diagnostic — tier/status must communicate precisely at a glance. Icons, meters, and color cues all carry the same signal. Earned — higher tiers carry visibly more light. Elite looks like it took work to reach.

10 · Accessibility Rules
Contrast
All tier labels pass AA 4.5:1 on bg.primary. Numerics (≥32px = "large") pass AAA. Status chip bodies always use text.primary not the tint color.
Non-color signal
Tier ALWAYS paired with label text (POOR / FAIR / …) + meter width. Status chip ALWAYS paired with distinct icon shape (check / triangle / X / info) — no red-vs-green reliance.
Color-blind patterns
Great / Success · check
Fair / Warning · !
Poor / Error · X
Touch targets
Tier cards tappable ≥ 44×44pt. Chips with actions (dismiss, retry) expose a 48×48pt hitbox around icon.
Reduced motion
On isReduceMotionEnabled: count-up → instant number · medallion pulse → static · confetti → single fade. Glow kept.
Light mode
Invert surface + keep tier base. Glows drop to alpha .15. Text swaps to text.inverse. Same component, two themes.

Stack: Moti for enter/exit + scale, react-native-linear-gradient for gradient numerics, expo-haptics for feel, react-native-reanimated for count-up. One <TierMedallion> component, used everywhere — Results hero, Progress sparkline thumbnails, Profile ring. Never re-implement.
12 · Before vs After
BEFORE
  • Flat squares — every tier looked the same shape
  • No progression visible — red 40 and green 80 had equal weight
  • Static — no reveal animation, no micro-interactions
  • Color-only signal — color-blind users got zero cue
  • Ad-hoc statuses — toast, banner, inline had 3 different shapes
  • Generic dashboard feel — could be any SaaS app
AFTER
  • Medallion identity — higher tier visibly earns more light
  • Meter + label + icon — meaning in 3 redundant channels
  • Cinematic reveals — count-up, ring pulse, tier promotion
  • Shape-coded statuses — check / triangle / X / info
  • One TierMedallion component — consistent everywhere
  • Stadium-broadcast feel — distinctly SHOOTRZ
