ACCESSIBILITY CONTRACT
Size-independent AA: every default/pressed/focused pairing clears 4.5:1 at the smallest label size (sm · 11px). Orange and danger shifted one step darker vs v2 so DM Sans 700 11px passes — not just ≥14px bold.

Focus ring: 3px rgba(20,199,224,0.40), always visible on keyboard/switch focus, never suppressed, sits outside the button (never clipped by overflow:hidden). Pressed and focused are visually independent.
5 · React Native Usage Notes
iOS
Shadow: spread shadow.glow.orange.ios directly into style.

Press: Pressable + Reanimated withSpring({scale:0.97}) · Haptics.selection() on press-in.

Focus: VoiceOver focus renders ring via wrapper <View> with borderWidth:3, borderColor:focus.ringColor. Never a shadow string.
ANDROID
Shadow: elevation:6. Requires solid backgroundColor. Colored glows only approximate — pair with inner border tint.

Press: android_ripple={{color:rgba(255,255,255,0.12),borderless:false}} + same scale anim · HapticFeedback.Effect.KEYBOARD_TAP.

Focus: TalkBack focus → same wrapper-border pattern as iOS.
Loading contract: swap label to gerund ("Analyzing", "Deleting", "Thinking"), replace leading icon with spinner, set accessibilityState={{busy:true}}, and disable onPress. Do not render both spinner and icon.
