4 · Accessibility
Touch targets
All inputs ≥ 44pt height (standard 48pt, chat 44pt). Send button 44×44pt — iOS HIG + Android Material floor. Tap area extends full input width.
Text contrast (AA)
Input text #F1F5F9 on #1C2432 = 14.8:1 AAA. Helper default #94A3B8 = 4.8:1 AA. Helper error #F87171 = 5.3:1 AA (brightened from base #EF4444 for small-text legibility). Placeholder #64748B = 3.1:1 — non-load-bearing, value always editable.
Focus distinctness
Focus = cyan border + 2px cyan ring. Success = green border, no ring. Default = neutral slate border, no ring. Three visibly distinct treatments — color + ring presence together, never color alone.
Non-color signaling
Error ALWAYS paired with alert icon (◉) + helper text. Success ALWAYS paired with check icon. Loading ALWAYS paired with spinner + status copy. Read-only ALWAYS paired with READ ONLY badge in label.
Screen reader contract
accessibilityLabel = field label. accessibilityState={{ disabled, busy }}. Error helpers linked via aria-describedby / RN accessibilityDescribedBy. Send button labelled "Send message" / "Sending" per state.
Reduced motion
Press-scale on send skipped when isReduceMotionEnabled. Loading spinners kept (continuous rotation is informational, not decorative). Focus ring is non-animated.
