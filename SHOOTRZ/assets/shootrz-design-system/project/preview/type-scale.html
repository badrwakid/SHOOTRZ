05 · TYPOGRAPHY
TYPE SCALEv2 · PRODUCTION READY
Two-family system: Barlow Condensed (display, numerics, energy) + DM Sans (everything else). 9 sizes → 11 semantic aliases. Built for React Native mobile-first legibility.
1 · Typography Strategy
Two voices, one system. Barlow Condensed is reserved for numerics and stadium-voltage callouts — the jumbotron typeface. It's loud on purpose and only used when the content earns it (your score, your streak, your section hero).

DM Sans does all the heavy lifting — every heading, every piece of body copy, every label and piece of meta. It has a warm, humanist geometry that reads quickly on small screens without feeling "app-generic".

Scale is musical, not mechanical. 11→13→15→17→20→24 on the body side, 30→38→48 on the display side. Each step is a perceptible jump; nothing nearly-matches-something-else.

6 · Hierarchy Enforcement
DO
  • Max 1 display.hero per screen. If you have two giant numbers, the hierarchy is broken.
  • Max 2 condensed styles per screen total (e.g. one hero number + one section callout).
  • Use DM Sans for all headings. Condensed is for numerics + stadium callouts only.
  • Vertical rhythm: 8pt between meta.caps and display · 12pt between heading and body · 20pt between content blocks.
  • Uppercase only for meta.caps + display.section. Never uppercase headings or body.
  • Let the scale do the work. Need emphasis? Bump one size up before reaching for color.
DON'T
  • Don't use Barlow Condensed for paragraphs. It's a display face; it tires eyes at small sizes.
  • Don't stack two 48px numbers vertically. One hero, rest scale down.
  • Don't invent sizes. Nothing between 17 and 20. No 14, no 18. If you feel the need — audit the hierarchy instead.
  • Don't uppercase body.sm or body.base. All caps kills readability below 14pt.
  • Don't mix font families within a sentence. Mono/display callouts go on their own line or as their own element.
  • Don't rely on weight alone for hierarchy — always pair with size change.
7 · Readability & Accessibility
Interactive minimums
Tap-target text ≥ 13px (tab bar label), button label ≥ 14px bold, form input ≥ 15px (prevents iOS zoom on focus). Never smaller.
Metadata minimums
body.xs (11px) is the floor — only for meta/overlines. Always paired with a larger primary element; never a standalone sentence.
Line-height discipline
Body 1.5, headings 1.2–1.35, display 0.95–1.0. Tight display, loose body. Breaks only at word boundaries — never mid-word.
Dynamic Type
Scale all roles up to 1.5× (extra-large). Condensed display clamps at 1.3× (it already runs tight). iOS allowFontScaling on by default except in fixed-layout badges.
iOS · Android deltas
Android renders ~0.5pt smaller. Add Platform.select +0.5 on body.sm / body.xs. Barlow Condensed tracks tighter on Android — add +0.3px tracking to display tokens on Android.
Font loading fallback
System-ui stack mirrors the metrics closely — no layout shift when web fonts arrive. Use font-display: optional on web surfaces.

9 · Migration Checklist
1
Add tokens first. Ship theme/typography.ts behind FF_TYPE_V2. Zero visible changes yet — tokens exist, nothing consumes them.
2
Introduce <Text role="…"> wrapper. One component that resolves a role to style. Every new feature uses it; old code gets migrated opportunistically.
3
Codemod existing <Text> usages that match common patterns — fontSize: 24, fontWeight: '700' → role="heading.h1". Flag ambiguous ones for manual review.
4
Screen-by-screen visual regression. Chromatic snapshots for Home, Analysis, Results, Progress, Chat, Profile — diff against baseline. Acceptable: ≤2px layout shift, 0 readability regressions.
5
Lint rule: no-inline-font-size blocks fontSize: N / fontWeight: … outside theme/. Error at PR-time; allowlist for migration-in-progress files.
6
Font loading audit. Verify Barlow Condensed Black / Bold and DM Sans Regular/Medium/SemiBold/Bold are bundled in the Expo asset manifest. Run on low-end Android device — no FOUT, no layout jump.
7
Flip FF on. 1% → 10% → 100% over one week. Rollback is a feature flag flip — safe by construction.
