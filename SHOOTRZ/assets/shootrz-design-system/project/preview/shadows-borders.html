RN USAGE
On iOS, spread the shadow object directly into style: style={[card, shadow.md.ios]}. On Android, apply { elevation: shadow.md.android.elevation } — the parent must have a solid backgroundColor or the shadow won't render. Colored glows (glow.orange/cyan) render on iOS only — Android elevation is always neutral black; pair with a translucent inner border to approximate the color tint.
