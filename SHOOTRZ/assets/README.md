# Assets Folder

## Required Files:

### SHOOTRZ Logo
Please copy your SHOOTRZ logo image to this folder and name it:
- `shootrz-logo.png`

The logo should be:
- High resolution (at least 400x200px)
- Transparent background (PNG format)
- Contains the SHOOTRZ text with basketball emojis and "PERFECT THE GAME" tagline

### Current Files:
- `icon.png` - App icon
- `splash-icon.png` - Splash screen icon
- `adaptive-icon.png` - Android adaptive icon
- `favicon.png` - Web favicon

## Usage:
The SHOOTRZ logo will be used in:
- Home screen header
- Profile screen
- Any other branding locations

Make sure to place your logo file as `shootrz-logo.png` in this folder for the app to display it correctly.
